# 🌍 Overview

Saarthi AI is an AI-powered Sales Intelligence Platform that automatically researches companies before customer meetings and produces concise AI-generated meeting briefings.


## ✨ Feature Section 1

Saarthi AI streamlines enterprise sales preparation through automation and AI.

### Highlights

- Automated company research
- AI-generated executive summaries
- Latest news aggregation
- Meeting preparation dashboard
- Opportunity and risk analysis
- Suggested talking points
- Modern responsive interface
- Flask backend with AI integrations

# 💻 Installation

```bash
git clone https://github.com/gallajagadeesh17/Saarthi-AI.git
cd Saarthi-AI
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

SECRET_KEY=
